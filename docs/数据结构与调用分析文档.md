### 5.2 数据加载方法

**异步加载机制**：
```kotlin
// 商品数据加载
suspend fun loadProducts(): List<Product> = withContext(Dispatchers.IO) {
    try {
        if (productsFile.exists()) {
            val jsonContent = productsFile.readText()
            val products: List<Product>? = gson.fromJson(jsonContent, listType)
            products ?: loadProductsFromAssets()
        } else {
            loadProductsFromAssets()
        }
    } catch (e: Exception) {
        loadProductsFromAssets()
    }
}

private fun loadProductsFromAssets(): List<Product> {
    val jsonString = context.assets.open("data/products.json")
        .bufferedReader().use { it.readText() }
    val listType = object : TypeToken<List<Product>>() {}.type
    return gson.fromJson(jsonString, listType)
}

// Banner数据加载
suspend fun loadBanners(): List<Banner> = withContext(Dispatchers.IO) {
    val jsonString = context.assets.open("data/banners.json")
        .bufferedReader().use { it.readText() }
    val listType = object : TypeToken<List<Banner>>() {}.type
    gson.fromJson(jsonString, listType)
}

// 消息数据加载
suspend fun loadMessages(): List<Message> = withContext(Dispatchers.IO) {
    val jsonString = context.assets.open("data/messages.json")
        .bufferedReader().use { it.readText() }
    val jsonObject = JsonParser.parseString(jsonString).asJsonObject
    val legacyMessagesJson = jsonObject.getAsJsonArray("legacy_messages")
    val listType = object : TypeToken<List<Message>>() {}.type
    gson.fromJson(legacyMessagesJson, listType)
}
```

## 6. UI层数据使用分析

### 6.1 MVVM模式数据流

**HomeViewModel** - 首页数据
```kotlin
class HomeViewModel(
    private val repository: DataRepository,
    private val context: Context
) : ViewModel() {
    
    private val _banners = MutableStateFlow<List<Banner>>(emptyList())
    val banners: StateFlow<List<Banner>> = _banners.asStateFlow()
    
    private val _products = MutableStateFlow<List<Product>>(emptyList())
    val products: StateFlow<List<Product>> = _products.asStateFlow()
    
    private fun loadData() {
        viewModelScope.launch {
            val bannersData = repository.loadBanners()
            val productsData = repository.loadProducts()
            
            _banners.value = bannersData.filter { it.isActive }.sortedBy { it.sortOrder }
            _products.value = productsData
        }
    }
}
```

**HomeScreen** - UI层消费
```kotlin
@Composable
fun HomeScreen() {
```

## 8. 关键特性与设计模式

### 8.1 数据加载策略

1. **懒加载** - 按需加载商品详情和规格
2. **缓存机制** - Repository单例模式缓存数据
3. **异步处理** - 使用Coroutines进行IO操作
4. **错误容错** - 加载失败时回退到Assets数据

### 8.2 数据持久化策略

1. **双重存储** - Assets + Internal Storage
2. **增量更新** - 只保存用户修改的数据
3. **JSON序列化** - 使用Gson进行数据序列化
4. **类型安全** - TypeToken处理泛型类型

### 8.3 响应式数据流

1. **StateFlow** - 响应式数据流管理
2. **观察者模式** - UI自动更新
3. **生命周期感知** - collectAsStateWithLifecycle
4. **状态提升** - 状态在ViewModel中管理
